# Spritesheets do Golem Ancião

`golem_all_animations_sheet.png` reúne todas as animações em uma grade de células 92×92. A imagem mede 1564×644 pixels (17 colunas e 7 linhas).

Ordem das linhas:

1. Idle — 11 quadros
2. Walking — 8 quadros
3. Charge run — 16 quadros
4. Ground crash — 17 quadros
5. Boulder throwing — 16 quadros
6. Taking damage — 7 quadros
7. Death — 17 quadros

O conteúdo pode ser deslocado no máximo 13 pixels para baixo sem cortar nenhuma animação. Não redimensione a imagem nem altere o tamanho das células. As células vazias no fim das linhas devem continuar transparentes.

As spritesheets horizontais individuais permanecem nesta pasta para uso direto pelo jogo. Os VFX foram convertidos separadamente em `golem_vfx/spritesheets`.
